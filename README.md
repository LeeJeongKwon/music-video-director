# Music Video Director

MP3와 SRT를 업로드해 노래 분위기와 자막 흐름에 맞춘 뮤직비디오 콘티, 이미지 프롬프트, 영상 프롬프트, 에셋 관리, 편집 타임라인을 구성하는 브라우저 앱입니다.

## 바로 열기

`열기.html`을 더블클릭하면 앱이 열립니다.

또는 `index.html`을 직접 열어도 됩니다.

## 로컬 서버 실행

```powershell
cd C:\Users\Admin\Downloads\chatgpt\music-video-director
npm start
```

브라우저에서 `http://localhost:8787`을 열면 됩니다.

## 구현된 기능

- 1단계: MP3 업로드, 같은 제목 SRT 자동 연결, SRT 별도 업로드, 선택 파일 목록 표시, 파일명 기반 제목 자동 입력, 참조 이미지 업로드, 재생시간/자막 줄/예상 씬 계산, 9:16·16:9·1:1·4:5 선택
- 2단계: SRT와 톤/연령대/옴니 기준 길이를 반영한 컨셉 3종 추천
- 3단계: 첨부 예시처럼 36개 스타일 프리셋 그리드 선택, 씬별 콘티, 선택 스타일이 강제 적용된 긴 이미지 프롬프트, 한국어 나레이션 포함 영상 프롬프트 생성
- 4단계: 3단계 선택 스타일을 그대로 반영한 프롬프트/에셋 관리, API 키 입력/테스트 UI, 설정 내보내기/불러오기, 프롬프트 일괄 복사 및 개별 저장
- 5단계: 첨부 예시형 Final Editor UI, 드래그&드롭 그림/ZIP/음원/SRT 업로드, 실시간 자막 입력·저장, 좌측 영상 미리보기, 우측 탭형 상세 설정, 타임라인 순서 조정, 클립 길이 슬라이더, 자막 스타일 세부 조절, 카메라 무빙 프리셋, CapCut 스타일 화면전환 프리셋, 무료 브라우저 TTS 미리듣기, BGM 선택 UI, 첫 페이지 타이틀 연출, 특수 비주얼 효과 UI, 최종 MP4 제작 버튼
- 종합: 프로젝트 저장/불러오기, 히스토리, API 키 제외 초기화, 전체 초기화, 로그 패널

## 다음 연결 지점

현재 앱은 프론트엔드 프로토타입입니다. 실제 이미지/영상 생성과 최종 MP4 렌더링은 백엔드 연결이 필요합니다.

- 이미지: OpenAI Images, Gemini, Stability AI, Replicate 등
- 영상: Google Veo/Flow, Runway, Pika, Luma 등
- 음성: 브라우저 Web Speech API 기본 지원, 고품질은 OpenAI TTS 또는 ElevenLabs 연결
- 최종 합성: FFmpeg 백엔드로 MP3, 업로드 클립, SRT, 타이틀 자막, 전환 효과를 합성

Google Flow는 공개 자동 실행 API가 없는 경우 브라우저에서 직접 생성 명령을 내리는 대신, 이 앱에서 복사 가능한 프롬프트 묶음으로 관리합니다.
